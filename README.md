# ゲーム画面風UI素材キット（見本）

映像作品に登場させる「ゲーム画面」の素材を、**規則を決めてから作る**とどうなるかを見せるための見本です。

公開先: https://higetuno-crypto.github.io/game-ui-kit-demo/

## 中身

| | |
|---|---|
| 画面 | 4点（探査中のHUD／海図・ソナー／装備・積載／通信ログ） |
| アイコン | 24点 |
| 設計トークン | 基本色7＋派生4・角丸0px・罫線1pxで濃さ3段・アイコン24×24座標系/線幅1.6/塗りなし・書体2種 |
| 対比 | 「規則なしで組んだ場合」と「トークンで組んだ場合」を同じ情報量で並べた1組 |
| トーン替え | 同じ構造のまま配色だけ差し替えた3案 |

## この見本の作り方

- **画像ファイルを1枚も読み込んでいません。** 背景・計器・アイコン・粒子・走査線はすべてSVGとCSS
- **画像生成AI（Midjourney・Stable Diffusion等）は使っていません。**画像ファイルが0枚なのはそのため
- **ただしコードはAI（Claude）を併用して書いています。**「絵を出させる」のではなく、
  規則を決めてコードに落とし、調整する工程にAIを使っている
- 外部の読み込み（CDN・フォント・スクリプト）は**0件**。`index.html` 1ファイルだけで表示できる
- ベクターなので、書き出す解像度を変えても劣化しない（4K・部分拡大とも）
- **縦画面は再レイアウトが必要。**16:9で組んでおり、縦型の配置規則は入れていない

## 確認したこと

ヘッドレスChromeで実際に描画して確認しています。

| 項目 | 結果 |
|---|---|
| 画面数 | 8（本編4＋対比1＋トーン替え3） |
| アイコン数 | 24（見出しの「24点」と一致） |
| 装備の枡 | 24（うち使用18／空き6。見出しの「18 / 24」と一致） |
| 外部読み込み | 0件 |
| 表示確認 | デスクトップ1280px ／ 携帯 390・375・360px（iframeで実幅を出して確認） |

**携帯幅では16:9の画面を潰さず、実寸のまま横スクロールさせています。**
潰すと定規・ソナー・操作行が重なって読めなくなることを、実際に描画して確認したうえでの判断です。

## 既知の制限

- **8〜9pxの文字がある**（ゲージ名・装備番号・定規・表見出し）。
  1920px幅での実寸は画面1,132×637px。**映像内で縮小配置すると最初に消える情報。**
  実制作では、載せる大きさに合わせて最小文字サイズを決める必要がある
- **縦画面には対応していない。** 16:9固定で、縦型の配置規則を入れていない
