UI ASSET KIT / SAMPLE

ゲーム画面風UI素材キット 深海サルベージを題材にした、画面4点・アイコン24点・設計トークン一式

ご依頼文にあった「既存素材をそのままバラバラにつなげると統一感のない画面になってしまう」 という点に、実物でお答えするために作りました。

この見本は生成AIを一切使わず、すべてコードで描いています（画像ファイルを1枚も読み込んでいません）。 アイコンも背景も計器もSVGとCSSです。ベクターなので、4Kでも縦画面でも、書き出し直せば劣化しません。 AI生成素材や有料UI素材と混ぜる工程は、この上に重ねる形でご用意できます。

06 — 統一感の作り方

上の4画面が揃って見えるのは、感覚ではなく、この表を守っているからです。 お渡しいただく既存素材やAI生成素材も、この表に合わせて調整すれば同じ組に入ります。 ご依頼のトーンが決まっているなら、最初にこの表をお作りして先にご確認いただく形が確実です。

COLOR — 7
7色しか使いません。赤（#d9603f）は危険の表示だけに予約し、装飾には一切使いません。
RADIUS
0px
角丸を全面的に禁止しました。これが「装置の画面」に見せる一番効く一手です。丸めた瞬間にアプリのUIに見えます。
HAIRLINE — 3
28% / 52% / 85%
線は1pxだけ。太さではなく透明度で3段の強弱を作ります。太い線を混ぜると画面が急に安く見えます。
LAYOUT
8の倍数 ／ 画面内は%
ページの余白は8の倍数（8/16/24/32/40/64/72/96）。 画面の中の部品は16:9に対する%で置いていますので、 書き出す解像度が変わっても位置関係が崩れません。
ICON
24box / 1.6px / butt
枡・線幅・端の形・塗りなしの4点を固定。この4つさえ揃えば、描き手が違っても同じ組に見えます。
TYPE — 2
mono / sans
数字と符号は等幅、日本語は角ゴシックの2種だけ。等幅は桁が動かないので、映像で数値が変化しても行が揺れません。
